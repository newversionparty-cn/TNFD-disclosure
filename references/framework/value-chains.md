# TNFD Value Chain Scoping

> Purpose: Use when direct operations are not enough to assess nature-related dependencies, impacts, risks, and opportunities.

## Source Status

- Source type: Official TNFD value chain guidance summary.
- Last reviewed locally: 2026-04-29.

## Core Principle

TNFD expects organisations to consider upstream and downstream value chains where material. Lack of full traceability is a data gap, not permission to ignore value-chain issues.

## Data Maturity Levels

| Level | Evidence | Use |
|---|---|---|
| V1 Known locations | Supplier/customer site coordinates | Best for spatial screening |
| V2 Regional proxy | Country, province, basin, commodity origin | Useful where exact coordinates are unavailable |
| V3 Category proxy | Spend, commodity, sector, or process data | Early screening only |
| V4 Unknown | No location/category data | Gap report and remediation plan |

## Output Template

```markdown
| Value-chain node | Direction | Data level | Location/proxy | Activity/commodity | Nature issue | Limitation | Next evidence |
|---|---|---|---|---|---|---|---|
```

## Do Not

- Do not call value-chain assessment complete if only direct operations were reviewed.
- Do not treat Scope 3 climate categories as a complete nature value-chain map.
- Do not invent supplier coordinates.

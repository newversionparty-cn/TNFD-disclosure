# TNFD General Requirements Gate

> Purpose: Use before drafting a TNFD-aligned report or running assurance-readiness review.

## Source Status

- Source type: Official TNFD requirements summary.
- Last reviewed locally: 2026-04-29.

## The Six General Requirements

| Requirement | What to check | Evidence examples |
|---|---|---|
| Materiality application | Which materiality lens is used and why | Board-approved materiality approach, investor/regulatory rationale |
| Scope of disclosures | Entities, activities, geographies, value-chain coverage | Reporting boundary, consolidation scope, value-chain scoping memo |
| Location of nature-related issues | Where dependencies, impacts, risks, and opportunities occur | Asset coordinates, supplier regions, sensitive-location screen |
| Integration with other sustainability disclosures | How TNFD links to ISSB/GRI/ESRS/local reports | Crosswalk table, shared metrics, report index |
| Time horizons considered | Short, medium, and long term definitions | Time-horizon policy, scenario assumptions, strategy planning horizon |
| Engagement with Indigenous Peoples, Local Communities and affected stakeholders | How affected stakeholders were identified and engaged | Stakeholder map, consultation records, grievance mechanism evidence |

## Gate Logic

Before generating a "complete TNFD report":

1. Mark each requirement as `complete`, `partial`, `missing`, or `not applicable with explanation`.
2. For `partial` or `missing`, provide a remediation action, owner, and deadline.
3. Do not call the report complete if any requirement is missing without explanation.

## Output Template

```markdown
| General requirement | Status | Evidence | Gap | Remediation |
|---|---|---|---|---|
| Materiality application | partial | ESG materiality memo, 2025 | No nature-specific rationale | Add TNFD materiality note |
```
